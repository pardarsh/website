# Security policy

This repository is a static website with no server-side code, forms or user
data. Security issues here are most likely to be things like a malicious or
hijacked external link, or an unsafe third-party resource.

## Reporting a vulnerability

Please **do not open a public issue**. Report privately through GitHub's private vulnerability reporting: open
the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, where, and how to reproduce it. You should get an
acknowledgement within a few days.

## Scope

Vulnerabilities in the Pardarsh infrastructure itself should be reported to
[pardarsh-core](https://github.com/pardarsh/pardarsh-core/security) instead.
